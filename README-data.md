# 数据来源与 MATLAB 接口

网站默认的 `public/data/recorded.json` 是用户压缩包内已有 MATLAB 图形曲线的回放数据。它不是本次重新运行 Simulink 得到的结果，也不是无人机实飞数据。桌面原始文件没有被修改。

## 已保存数据

源文件：`挑战杯/倾转四旋翼无人机(1).zip` 内的 `figure1.fig` 至 `figure8.fig`。图例将这组数据标记为 PID；不能据此建立 PID 与容错滑模算法的性能对比。

通过只读解析 FIG 的 MATLAB Level-5 `hgS_070000` 图形结构提取数值，没有执行原始 MATLAB 脚本或图形回调。各时间曲线使用相同的 4001 个采样点，时间为 0–40 s，步长为 0.01 s；没有为了动画另造时间轴或按数组长度猜测时间。

| 网站字段 | 来源 | 处理 |
|---|---|---|
| `t` | 原图曲线的 `XData` | 原始秒值 |
| `refX/refY/refZ` | figure1 的 xd/yd/zd 曲线 | 原始米值 |
| `x` | figure1 的 x 曲线 | 原始米值，并与 `refX-ex` 逐点验证 |
| `y/z` | figure1 的参考曲线、figure2 的 ey/ez | `y=refY-ey`，`z=refZ-ez` |
| `ex/ey/ez` | figure2 三通道位置误差 | 原始米值，误差定义为参考减实际 |
| `roll/pitch/yaw` | figure3 的 φ/θ/ψ | 原图已经是弧度 |
| `eRoll/ePitch/eYaw` | figure4 的三通道姿态误差 | 原图已经是弧度 |
| `u1/u2/u3/u4` | figure5 | 保留原始数值，原图未标明物理单位 |
| `w1/w2/w3/w4` | figure6 | 保留原始数值，不能直接标为 RPM |
| `tilt` | figure8 的 β | 原始角度乘 π/180，单独转换为弧度 |
| `savedFigureY/savedFigureZ` | figure1 原始实际位置点 | 留存原图恒值 1、0，便于审计，不用于动画 |

## 为什么重建 y、z

原 figure1 的实际 y、z 是 4001 个独立点对象，值分别恒为 1 和 0；figure7 的实际轨迹同样如此。这与 figure2 中保存的动态位置误差不一致，无法把这两条原始位置曲线当成可信飞行轨迹。具体是变量覆盖、绘图时数据类型错误还是不同批次数据混用，现有文件不足以确定。

为回放原图已有的跟踪行为，本网站使用原图参考位置与误差重建 y、z，并在界面和 JSON 元数据中标明。符号不是根据动画效果猜测：静态检查 `matlab2018b.slx` 中 `simulink/systems/system_584.xml` 的位置控制器，Sum 块 SID 598、612、622 的 `Inputs=+-`，xd/yd/zd 接第 1 输入，x/y/z 接第 2 输入，输出分别写入 ex1/ey1/ez1。因此实际位置为“参考位置减误差”。x 通道有独立有效曲线，`x` 与 `refX-ex` 的逐点差小于 1e-12 m。

这确认了恢复公式与模型一致，但无法确认所有保存图形来自完全相同的一次运行。最终论文实验数据、性能结论与安全验证，应以重新运行模型并直接导出的日志为准。

恢复后的坐标范围：x 约 0.997492–1.002534 m，y 约 0–10.182974 m，z 0–2.011928 m。倾转角范围 0–45°。所有 4001 点都保留；JSON 不含 NaN/Infinity。

## 坐标与三维显示边界

约定世界坐标为右手系，z 向上，姿态矩阵 `Rz(yaw) Ry(pitch) Rx(roll)`。roll/pitch/yaw 沿用 `PLOT01.m` 的 φ/θ/ψ 标注；原 `UAVvideo.m` 对 fan、psi 的转轴分配与此存在差异，网站采用上述明确约定，应在后续建模时与论文坐标定义统一核验。

内置实验在沿世界 +Y 穿越时，原始偏航约为 60°。三维穿缝示意通过 `metadata.scene.headingOffsetRad=-π/3` 校准显示航向，使模型机头及局部 Y 倾转轴沿通道，正 β 表现为右侧降低。显示矩阵为 `Rz(yaw+headingOffsetRad) Ry(pitch) Rx(roll)`，保留原始偏航变化和微小姿态变化；这是显示约定，不是对原始坐标系的重新认定。4,001 个采样及原始姿态读数、曲线、导出角度不变；JSON 同时保存此显示约定。未声明该字段的导入文件不会自动校准。近景从机尾观察，可用“沿通道”视角检查横向占宽。

原绘图脚本把姿态角标成 rad，把倾转 β 标成度，不能把全部角度用同一阈值自动判断单位。网站仅将 β 从度换算成弧度。三维机体、旋翼转动、墙体和穿越通道是显示示意；不是碰撞检测、实物尺寸验证或空气动力学计算。

### 狭缝穿越的显示尺寸修正

三维模型的旋翼中心半距采用 `UAVvideo.m` 基础值：x 方向 0.079 m、y 方向 0.088 m，桨盘半径 0.065 m，电机半径 0.009 m、高 0.018 m，机架厚 0.022 m。未叠加原动画的 `VISUAL_SCALE=1.5` 展示放大。机架采用两条横臂与中央纵体，外壳等细节仍是示意。整个回放保持固定尺寸，不在进入通道时缩小机体，也不改变位置、姿态或倾转数据。

通道墙体内表面在 x=0.8 m 和 x=1.2 m，标注的 0.40 m 为真实的显示净宽；0.018 m 墙厚向通道外侧延伸。倾转细节由独立相机放大观察，不影响主场景的米制模型。

几何回归检查读取采用相同显示航向校准的实际渲染模型，覆盖 0–40 s 的 20,001 个记录及插值时刻（2 ms 间隔），包含机架、电机与完整桨叶旋转扫掠包络；与墙体纵向及高度范围重叠的 3,604 帧最小单侧显示净距约 75.27 mm。13.33 s、18.79 s 与 25 s 另检查机头沿通道、右侧降低和前倾幅度；18.79 s 以 72 个旋翼相位检查实际网格顶点。此检查用于避免当前内置回放穿模，不是连续时间证明、任意导入轨迹的避障保证或实机通行验证。

## 从新的 MATLAB 仿真导出

`matlab/export_demo_data.m` 接收你显式传入的信号结构，验证时间递增、长度一致、数值有限和角单位后生成网站可导入的 JSON。函数不会运行模型，也不会自动读写基础工作区。将它所在文件夹加入 MATLAB 路径，完成一次真实仿真后执行：

```matlab
s = struct;
s.t=t; s.x=x; s.y=y; s.z=z;
s.roll=fan; s.pitch=theta; s.yaw=psi; s.tilt=beta;
s.refX=xd; s.refY=yd; s.refZ=zd;
s.u1=u11; s.u2=u21; s.u3=u31; s.u4=u41;
s.w1=w11; s.w2=w21; s.w3=w31; s.w4=w41;
m = struct('title','新的 PID 仿真实验', 'source','matlab2018b.slx', ...
           'controller','PID', 'description','本次仿真直接导出的工作区日志');
export_demo_data('my-run.json', s, 'rad', 'deg', m);
```

当前 `.slx` 的位置和姿态输出变量叫 x/y/z/fan/theta/psi；`PLOT01.m` 则读取 x1/y1/z1/fan1/theta1/psi1。按自己运行后实际存在且正确的变量显式映射，不要直接复用旧工作区变量。如果 beta 在你的模型中已经是弧度，将最后一个单位参数改为 `'rad'`。

所有位置须为米、时间须为秒；必需字段为 t、x、y、z、roll、pitch、yaw、tilt、refX、refY、refZ。u1–u4、w1–w4 及误差字段可省略。信号可为数值向量或单通道 `timeseries`；各信号必须处于同一时间网格，函数会拒绝错位数据，不会按数组长度偷偷重采样。导出后使用网站的 JSON 导入按钮即可回放。网页只读取选中的本地文件，不会上传到外部服务器。

### JSON 结构

```json
{
  "schemaVersion": 1,
  "metadata": {
    "title": "实验名称",
    "source": "实验数据来源",
    "kind": "recorded",
    "angleUnit": "rad",
    "positionUnit": "m",
    "timeUnit": "s"
  },
  "samples": [
    {"t":0,"x":1,"y":0,"z":0,"roll":0,"pitch":0,"yaw":0,"tilt":0,"refX":1,"refY":0,"refZ":2},
    {"t":0.01,"x":1,"y":0,"z":0.001,"roll":0,"pitch":0,"yaw":0.01,"tilt":0,"refX":1,"refY":0,"refZ":2}
  ]
}
```

上述两点仅用于说明格式，不是实验数据。真正的教学合成数据应将 `metadata.kind` 写成 `synthetic`，并明确说明生成方式。导出函数已做代码核查，但当前环境未完成 MATLAB 函数运行验证。
